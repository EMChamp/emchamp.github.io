Two live products and an open-source tool built at nights and weekends. I am listing the experiments for what they taught me about failure modes, because the useful lesson from each was never the feature. It was the moment the obvious approach turned out to be wrong.

The Vibe Coding Report ↗
A serverless news aggregator and intelligence platform for the AI developer tools ecosystem, running unattended and publishing daily. It scans the agent, model, IDE, cloud, and builder landscape, then reduces each development to a single line worth reading.
The whole thing is vibe coded, which is the point. It is a working argument that an agent-built system can hold up in production and keep publishing without a person in the loop every morning.

winnow ↗
A four-stage Python pipeline that scores 700+ 4K clips on per-frame motion and sharpness, then cuts the dead footage. NVDEC hardware decode took the render from 1.03x to 3.90x realtime.
What brokeA "cut anything still for twelve seconds" rule would have carved 22 seconds out of a beautifully composed held wide shot. A parked camera and a deliberate one are identical to the metric. Intent is not measurable, so the heuristic had to go.
